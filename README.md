# Kenny Yu Portfolio

A zero-dependency, multi-page portfolio built with HTML, CSS, and JavaScript. The homepage introduces Kenny's work, while `bambi.html` is an editorial photo page about Bambi and the desktop companion project.

## Run locally

From this directory:

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

## Files

- `index.html`: homepage content and the inline hero illustration
- `bambi.html`: Life with Bambi photo page and project bridge
- `styles.css`: design system, responsive layout, and motion
- `script.js`: pointer tracking and progressive reveal behavior
- `brand-spec.md`: approved visual direction and content guardrails
- `assets/`: verified project media and the local resume copy
